# Valyuta kursi

Ishga tushirish:

1. Shu papkada: `flutter create .`   (android/ios papkalarini yaratadi, lib/main.dart ga tegmaydi)
2. `android/app/src/main/AndroidManifest.xml` ga `<application>` dan oldin qo'shing:
   `<uses-permission android:name="android.permission.INTERNET"/>`
3. `flutter pub get`
4. `flutter run`
